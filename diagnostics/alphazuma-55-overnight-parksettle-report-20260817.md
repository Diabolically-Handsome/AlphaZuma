## 二、夜间因果链（每一步都有收据）

1. **修好仪表**（度量模块 + 探针 V4）→ 测出旧「95% 一致」是分母稀释假象；真实瞄准误差 77°、on-target 10.7%、决策相关分歧 71–95%。V3 按原设计会虚假通过（分母花招已被 V4 门控测试锁死）。
2. **修训练信号**（停靠-安定配方：全 tick 瞄准监督 + 精确掩码 + 无强制重平衡）→ 发现新问题：不加类权重则 verb 头塌缩为永不开火（6×10⁻⁶）；用合法 tick 分布的平方根逆频率权重 [1, 5, 7.5, 47.5] 校准至教师开火率的 0.86–1.27 倍。
3. **闭环仍崩** → 定位残余根因：**光标反馈分布偏移**——同一模型瞄准意图 p50 在教师驾驶时 2–8 bin、自驾时 27–43 bin。静态能力（窗口 within-3 从 56%→85%）不迁移到闭环。
4. **DAgger 轮次 1**（学生执行、教师逐 tick 反事实标注，110 回合 51 万失稳态 tick）→ p50 43→27、分数 110→4,540：收敛但每轮增益有限。
5. **宏协议评估（决定性实验）**：把「驱动光标→安定→开火→持稳」交给确定性代码，策略只在炮膛就绪时选目标 → **73 发射击 100% 精确命中所选目标（0.0 bin 误差）**。运动执行的墙被彻底推倒。
6. **最后的瓶颈**：宏决策点上模型开火频率仅教师的 1/20，且所选目标平均每枪仅得 ~29 分——**何时开火、打哪里的决策质量**是剩下的全部问题。
